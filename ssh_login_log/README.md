# SSH 登录审计 · 宝塔面板插件

在面板里按 **IP / 时间 / 端口 / 状态 / 用户** 查看 SSH 登录记录，并对爆破来源一键封禁。

- 插件名：`ssh_login_log` · 版本 2.5
- 安装位置：`/www/server/panel/plugin/ssh_login_log/`
- 面板入口：软件商店 → 已安装 → SSH登录审计 → 设置

## 安装

面板 → 软件商店 → 导入插件 → 选择本目录下的 `ssh_login_log-2.5.zip`。

装完若界面还是旧样子，`Ctrl + F5` 强刷（面板对插件页有 24 小时静态缓存）。

## 功能

| 页签 | 内容 |
| --- | --- |
| 认证事件 | 成功 / 密码错误 / 无效用户 / 尝试超限 / 认证中断；含来源 IP、源端口、认证方式（password、publickey）、会话时长、原始日志行 |
| 当前在线 | `who` + `ss` 合并：用户、终端、登录时间、来源 IP、源端口、已在线时长、sshd 进程 PID |
| 失败排行 | 失败 IP Top8、被尝试用户名 Top8，每行可直接 **禁用 / 解禁**；同一 `/24` 内失败 IP 数达阈值时列出该网段，一键 **封禁 / 解禁网段** |
| 白名单 | IP 或 CIDR；白名单内的地址禁止封禁，加入白名单时若已被封禁会自动解禁 |
| 设置 | 回读上限、保留事件数、自动刷新、网段阈值、默认时间范围、默认页签、主题 |

顶部另有今日成功 / 今日失败 / 失败来源 IP 数 / 当前在线四项统计与 24 小时双色柱状图，支持按当前筛选导出 CSV（含 BOM，Excel 直接打开）。

## 数据来源

按顺序自动探测，存在即用：

1. `/var/log/auth.log`（Debian / Ubuntu）、`/var/log/secure`（CentOS / RHEL）、`/var/log/messages`，含 `.1`、`.2.gz`、`-YYYYMMDD` 轮转文件
2. 以上都没有时回退 `journalctl -t sshd -t sshd-session`
3. `/var/log/wtmp`（成功登录）与 `/var/log/btmp`（失败登录）二进制补充——日志轮转后仍可回溯；与日志重复的记录按 用户 + IP + 时间 去重

单文件默认只回读尾部 8MB（可调），解析结果缓存在 `/dev/shm`，60 秒内不重复解析。

## 封禁实现

优先调用面板防火墙接口（`firewall_new.firewalls().AddDropAddress`），规则会出现在 **面板 → 安全 → 防火墙**；
接口不可用时依次回退 `ufw` / `iptables`。解禁同时清理面板记录与系统规则，支持 CIDR（如 `45.148.10.0/24`）。

## 设置项

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 日志回读上限 | 每个日志文件最多读取的尾部大小 | 8 MB |
| 保留事件数 | 解析后最多保留的事件条数 | 20000 |
| 自动刷新 | 前端轮询间隔，0 为关闭 | 0 秒 |
| 网段阈值 | 同一 /24 内出现多少个 IP 时提示封禁网段 | 5 个 IP |
| 默认时间范围 | 打开时默认选中的时间窗 | 3 天 |
| 默认页签 | 打开时默认停留的页签 | 认证事件 |
| 主题 | 跟随面板 / 浅色 / 深色 | 跟随面板 |

## 实现要点

- 后端方法名即接口名，前端走 `/plugin?action=a&name=ssh_login_log&s=<method>`
- 面板 13.x 对 `/plugin` 强制校验 `x-http-token` 请求头，缺失返回 `INIT_CSRF_ERR`（界面显示「权限认证失败」）。前端依次从父窗口 `window.vite_public_request_token`、`#request_token_head` 节点、cookie 取 token
- 页面按容器真实宽度排版：窄容器（面板弹窗常见 570px）按列优先级折叠源端口 / 方式 / 时长等次要列，避免挤压截断
- 主题优先跟随面板，读不到面板才回退系统偏好

## 已知边界

- 只解析 IPv4 网段（IPv6 地址正常展示，但不参与 /24 分组与网段封禁）
- 失败次数统计基于当前读到的日志窗口，非全量审计库
- 面板插件无热重载：改代码后需重新打包并覆盖安装
